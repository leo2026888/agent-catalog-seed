其余待审阅成果分为产品、文章与 Skills 三类，具体源文件仅列在仓库外的私有清单。确认后，每项增加一张 [成果卡](../templates/showcase-item.md)，保留公开版本、实际作者、素材权利、功能状态和后续修改记录。公开 Skill 的指令与合成能力示例分开展示；作者自述不作为独立效果证据。

展示文字区分“已运行”“试点”“原型”“计划”和“未核验”；公开前用当前证据更新。客户名称、报价、电话、人物照片、内网地址与其他受限材料不能因新建入口而自动公开。
