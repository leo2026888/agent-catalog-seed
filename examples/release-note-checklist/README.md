# 发布说明转检查清单：合成示例

这是一组本次新写、AI 辅助整理的虚构材料，用来演示目录如何记录来源、权限、预期行为和证据空缺。它不是可安装 Skill，也不包含插件程序或 `SKILL.md`。

- 输入：[input.md](input.md)。虚构产品 Quiet Notes，不代表真实产品或客户。
- 预期输出：[expected-output.md](expected-output.md)。这是人工审阅用的期望样例，不是运行结果。
- 目标：只根据输入，将明确变更转为可勾选检查项；保留“计划中”“未知”的边界。
- 失败情形：编造发布日期、声称已修复或已通过测试、把计划功能写成已上线、增加输入没有的用户信息。
- 本示例未运行、未安装、未评测，也未验证任何主机兼容性。没有网络请求、外部接收端或客户数据。
