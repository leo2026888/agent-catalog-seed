本地准备、GitHub 创建、推送成功和匿名公开读取是不同状态。只有当前阶段完成，才更新相应记录。

## 一次确认的发布范围

- [ ] 已回读 GitHub 登录用户名，并确认仓库属于该个人或组织。
- [ ] 确认工作名 `agent-catalog-seed` 和本次新写首包范围；名称可用性另行检查。
- [ ] 核对代码/Schema/合成示例的 MIT 正式文本、文档的 CC BY 4.0 范围及 Leo and contributors 署名；条目为 `MIT` / `declared`，未将许可延伸到历史或第三方材料。
- [ ] 已配置实际维护者；私密安全渠道已配置验证，或仍明确声明不可用。
- [ ] 未将仓库外的私有选材清单、访问记录和历史未授权材料加入 Git。

- [ ] 人工检查全部首批文件和 Git 暂存清单；路径、私人信息、第三方权利与能力表述均已检查。
- [ ] 修改后重新生成摘要；ZIP 只包含清单内的仓库文件，不含 `.git`、缓存或私有审阅记录。

- [ ] 首个 release 只链接已校验的文件；不把传输成功表述为读者验收。
