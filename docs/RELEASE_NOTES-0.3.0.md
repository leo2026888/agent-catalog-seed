# v0.3.0-seed 发布说明

发布日期：2026-09-06。作者：Leo and contributors，AI辅助实现与整理。本文依照本仓库文档范围采用CC BY 4.0。

本版把Agent Catalog从5条深度样本扩充为21条公开目录记录，并将目录规模、公开资料评分、任务效果和社区评分拆分为不同证据层级。

- 新增16条GitHub高星MCP／Skill工具候选，覆盖代码文档、浏览器调试、代码库检索、研究、工作流、AWS、绘图、抓取和应用开发。
- 每条候选公开星数、fork、watcher、开放问题、合并贡献、许可元数据、最近推送和最新Release字段。
- 增加透明的公开资料评分及分项；该分数不包含任务效果、安全结论或真实用户满意度。
- 增加社区使用评分Issue表单；提交后需人工核验，当前聚合评分样本仍为0。
- 自有只读查询扩充到21条记录，并继续返回未运行、权限待查和宿主兼容未知等边界。

本版没有安装或执行第三方候选，没有复制第三方源码或软件包，也没有把星数和公开协作数量换算成实际效果。16条新候选仍需进入权限文档、静态检查、隔离运行或真实任务评测后，才能得到相应层级结论。
