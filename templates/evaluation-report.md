# 评测报告模板

> 模板；尚未执行任何评测。复制后填写全部字段，未知填“未知”，未执行填“未执行”，不适用项附理由。不得把占位值、示例或计划写成结果。字段结构需与[条目 schema](../schema/entry.v0.1.0.schema.json)一致；方法见[评测方法](../docs/EVALUATION.md)。

## 报告身份与结论

- 报告 ID / 版本：待填写
- 报告状态（草稿、已审阅、待复核、过期、撤回）：待填写
- 证据类型（作者声明、静态检查、运行观察、社区观察；分别列出）：待填写
- 一句话结论及适用范围：待填写
- 明确未验证的能力与风险：待填写
- 评测者 / 审阅者（尚无审阅者时注明）：待填写
- 作者自测或独立复核：待填写；未独立复核时不得使用独立认证措辞
- 与作者、供应方、竞争方的关系及赞助条件：待填写
