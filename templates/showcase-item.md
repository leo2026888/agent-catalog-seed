# 成果卡模板

- 标题、类型（产品 / 文章 / Skill）、简短说明：待填写。
- 作者与权利人、共同作者/单位权利：待确认。
- 公开来源链接、版本、发布日期、当前核验日期：待填写。
- 状态（已运行 / 试点 / 原型 / 计划 / 未核验）：待选择并附依据。
- 本次允许公开范围（文字 / 代码 / 图片 / 附件）：待逐项确认。
- 素材来源、许可、署名、修改说明：待填写。
- 依赖平台、权限、已知局限：待填写。
- 客户/人员信息、报价、内部链接与凭证检查结论：待复核。
- 变更摘要、审阅者与同意公开的记录：待填写。

没有公开权利依据的正文不附在卡片中；内部材料先留在私有选材清单。条目与体验评价请分别维护。
